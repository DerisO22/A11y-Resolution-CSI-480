# CSI 480 - Final Project

### Evaluating LLMs on A11y Resolution
By Deris O'Malley

## Purpose
Accessibility for public-facing webpages is considered one of the most important aspects in front-end web development, since following good accessibility practices is impactful for better SEO, usability for all users, and legal compliance (WCAG, ADA, etc.). Evaluating an LLM’s ability to reason through common accessibility problems can help determine if these tools are currently capable of being tasked to fix them. If these models can reliably solve these considerably tedious problems, it can drastically boost a developer's productivity and free their time to focus on other aspects of development. The main application of this research in relation to software engineering will focus on building automated tools for GitHub actions/Git hooks integration that can scan and fix accessibility issues on a webpage’s codebase utilizing LLMs.
